# Project registration — by explicit instruction only

Set by Banks 2026-11-07. Complements `registry-before-build.md`.

## The rule

A new repository, project or workstream must NOT be added to the AIOS — no
`projects/<name>/` entry, no AGENTS.md mention, no connections.md or index
edit — unless Banks specifies it for that project first ("link it", "add it
to the AIOS", "track it here"). One instruction registers one project; a
"yes" for Speakrite is not a "yes" forever.

## What agents may still do

- Check the registry before building anything (registry-before-build).
- Clone, read, work on and deploy a repo that Banks pointed at, using a
  scratch or the agreed local folder — working in a project is not
  registering it.
- Note status in the conversation or the task list item that produced the
  work, without creating a permanent `projects/` entry.

## When unclear — ask, don't assume

If it is ambiguous whether something should be registered: ask one short
question ("Keep X in the AIOS index — yes or no?"). Prefer a 10-second
question over a wrong permanent entry, and prefer asking over stalling.

## Removal

Deleting or moving an existing `projects/` entry also needs Banks's word —
history moves to `archives/`, never vanishes.
