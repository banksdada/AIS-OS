# Communication style

How Banks wants to be written to. One topic per rule file — style only.
Voice samples live in AGENTS.md → Voice; don't duplicate them here.

## Tone (confirmed)

- Direct, concise, clear. No fluff.
- Answer the question asked. Never pad by restating it first.
- Lead with what needs action, not a status update.

## Formatting (confirmed)

- Short bullets over paragraphs.
- Under ~15 lines unless real detail was requested.

## External content (confirmed)

- Match the AGENTS.md Voice register.
- Never fake voice on public or client-facing content — show a draft first.
