# Products built by WebAwesome

These are real systems built and run by WebAwesome. Availability differs: some
are live products, some are client platforms, some are internal tools we can
adapt for a client. Do not promise a sign-up link or a public price unless it
appears in this file.

## AI Readiness Audit

Customer-facing AI adoption audit: 12-question questionnaire, scored
Crawl / Walk / Run maturity, one-page summary plus full report with PDF export.
Live at https://ai-audit.webawesome.co.uk.

## Webby (this assistant)

A website agent with a single knowledge base shared by two doors: a chat widget
on the site and a command-line agent. It answers from WebAwesome content, shows
live TidyCal discovery slots, books the free 15-minute call and captures leads
with human handoff.

## AIcare

Care management platform for UK domiciliary care, care homes, nursing homes and
supported living. Laravel 12 with a Filament admin panel and PostgreSQL
schema-per-tenant. Built for care providers.

## Flux (job intelligence)

Self-hosted dashboard where a job seeker uploads a CV and the system scans job
sources on a timer, scoring each posting against the candidate's actual skills.

## Deal Desk (property deal finder)

Web app that scores UK property listings for flips and investor deals: add or
upload listings, work a ranked inbox, full cost breakdown per deal.

## WebAwesome Scheduler

Job management SaaS for cleaning and pest-control style businesses: customers,
job scheduling with conflict checks, and feature flags per project.

## RotaMate

Rota and shift planning platform for teams, with group-aware roles and
scheduling, including automated health checks.
