# Knowledge

`knowledge/` is what Webby answers from. Files added here are read on every
request (no restart needed), capped at 6000 characters of matched context.

- `site/` is generated by `tools/scrape_site.py` from public WordPress pages.
- Hand-written pages here (products, AI audit, FAQ) win because they are scored
  alongside and usually match more query terms. Keep them short and factual.
- Never put secrets, client names without permission, or prices that are not
  approved in this folder.
